Just think about it

In many real-life situations, people need to locate a specific item from a large collection of ordered information. For example, finding a name in a telephone directory, searching for a word in a dictionary, locating a contact in an alphabetically sorted list, or looking up a record in a database. Checking each item one by one is time-consuming and becomes increasingly inefficient as the amount of data grows.

This raises an important question: How can we quickly locate the required item while minimizing the number of comparisons? Solving this problem requires a systematic search strategy that reduces unnecessary effort and improves efficiency.

The idea behind it

Binary Search, Explained

🎯

Binary Search finds a value inside a sorted collection by repeatedly checking the middle element and discarding the half that can't contain the answer. It starts with low = 1 and high = n — the first and last positions of the collection. The target is compared against the value at the middle position: if they match, the search is over. If the target is larger, everything up to and including the middle is discarded; if it's smaller, everything from the middle onward is discarded. This process of recomputing the middle, comparing, and narrowing the range repeats until the target is found or the range collapses entirely, meaning it isn't present.

The Formula
mid = ⌊ (low + high) / 2 ⌋

Match → done. Target larger than mid → low = mid + 1. Target smaller → high = mid − 1. Repeat.

Guess the Number

Finding a Word

When It Does Not Work
Consider the list 18, 4, 27, 9, 35, 12, 21. Can you directly apply Binary Search to find 12? Explain what prevents you from doing so and what would have to change.
04
Changing the Problem
A sorted list contains repeated values: 2, 4, 4, 4, 7, 9, 12. You need to find the first occurrence of 4, not just any occurrence. How would you modify the idea of Binary Search?
05
Beyond Searching
A machine can operate at speeds from 1 to 10,000 RPM. You want to find the highest speed at which it operates safely. Testing every possible speed would take too long. Assuming that once a speed becomes unsafe, all higher speeds are also unsafe, explain how the idea behind Binary Search could help you find the boundary efficiently.
